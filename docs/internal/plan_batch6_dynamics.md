## 判据

- home、ready、target 和限位内随机姿态：质量矩阵维度正确且有限，最大非对称误差 < 1e-12，最小特征值 > 0；重力向量维度正确且有限；静止科氏项 < 1e-9 Nm；正逆动力学往返误差 < 1e-8 rad/s²。
- 五臂共同动力学/前馈使用无附加负载模型；前馈全部有限且在执行器力矩范围内。随机姿态的自碰撞/地面碰撞仅分类记录。
- 复用 `CollisionChecker`，保留 MJCF 接触过滤，仅忽略 `link_base` 与 `world` 的固定安装接触，不忽略运动连杆与地面。
- 命令序列 home→ready→target→ready：部署 1.5 s，往返各 3 s，每段后收敛 0.3 s。先按物理步长预检所有命令，失败则不开始运动。
- 示例内的受监测 `SimRobot` 子类每步积分后把实际关节位置送入独立 checker 重算接触。依据 [MuJoCo 执行顺序](https://mujoco.readthedocs.io/en/latest/programming/simulation.html)，不能直接使用积分前计算的接触。
- 实际运动最大穿透 ≤ 1e-6 m，最大关节越界 ≤ 1e-6 rad，每阶段收敛后最大到位误差 < 0.01 rad。非有限状态、数值警告、时间异常、提前结束均失败。
